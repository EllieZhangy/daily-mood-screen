Daily Mood Screen is a bilingual macOS project that turns live weather, recent photos, and a small mood engine into a new desktop wallpaper each morning. It generates a short line of writing, creates or selects an atmospheric background, renders the final composition, and archives the result automatically.

> **Project status:** working personal prototype for macOS. It can run as a menu bar app, from the command line, or on a daily `launchd` schedule. Users supply their own model and optional weather credentials.

## At a glance

| | |
| --- | --- |
| **Inputs** | Local weather, recent photos, language, and writing/visual preferences |
| **Output** | A daily wallpaper plus a dated archive copy |
| **Primary experience** | Double-clickable macOS menu bar app |
| **Automation** | Apple Shortcuts + `launchd` |
| **Personalization** | 32 weather × photo-theme mood combinations |
| **Languages** | Simplified Chinese and English |
| **Fallback** | Atmospheric gradient backgrounds when AI imagery is disabled |

## Why this project

Most wallpaper generators stop at a prompt box. Daily Mood Screen explores a more personal loop:

1. **Use real daily context** rather than a fixed prompt.
2. **Translate context into a visual and writing direction** through a reusable mood/style system.
3. **Deliver the result automatically** in a format that becomes part of the desktop instead of another file to manage.

## How it works

```text
8:00 AM — Daily Mood.app or launchd starts the pipeline
  │
  ├─ Read live weather and location
  ├─ Load up to five recent photos exported by Apple Shortcuts
  ├─ Classify the photo theme with vision AI
  ├─ Combine weather × photo theme into one of 32 moods
  ├─ Generate an atmospheric background or use a gradient fallback
  ├─ Generate a short bilingual quote from the selected writing style
  ├─ Render typography and metadata with Pillow
  ├─ Save output/daily_wallpaper_mac.png
  └─ Archive a dated copy in archive/YYYY-MM-DD.png
```

## Recommended experience: Daily Mood.app

The menu bar app avoids terminal setup after the initial build.

### Build

```bash
git clone https://github.com/EllieZhangy/Daily-Mood-Screen.git
cd Daily-Mood-Screen
bash build_app.sh
```

The build creates `dist/Daily Mood.app`. Move it to `/Applications` and launch it normally.

### First launch

1. Open **Daily Mood.app**; a sun icon appears in the menu bar.
2. Choose **Set OpenAI Key…**. The key is stored in macOS Keychain, not in a project file.
3. Optionally choose **Set WeatherAPI Key…** for live weather.
4. Choose the output and archive folders.
5. Click **Run Now** to generate the first wallpaper.

### Menu options

| Item | Purpose |
| --- | --- |
| **Run Now** | Generate today's wallpaper immediately |
| **Language** | Switch between 中文 and English |
| **Set OpenAI Key…** | Store or replace the model key in macOS Keychain |
| **Set WeatherAPI Key…** | Configure live weather data |
| **Output Folder…** | Choose where the current wallpaper is saved |
| **Archive Folder…** | Choose where dated copies are stored |
| **Last run** | Show the latest successful generation time |

App preferences are saved under `~/.config/daily_mood/`; secrets remain in macOS Keychain.

## Command-line quick start

Requires macOS and Python 3.11 or later.

```bash
git clone https://github.com/EllieZhangy/Daily-Mood-Screen.git
cd Daily-Mood-Screen
pip install -r requirements.txt

export OPENAI_API_KEY="your-key-here"
export WEATHERAPI_KEY="your-weather-key"   # optional when using fallback context

python main.py
```

For a manual city fallback, create `city.txt`:

```text
Los Angeles
```

The current wallpaper is written to:

```text
output/daily_wallpaper_mac.png
```

Add that file in **System Settings → Wallpaper**, then set rotation to **Never** so macOS keeps reading the updated file.

## Daily automation

The included `run_daily.sh` can be called by `launchd` every morning. A typical LaunchAgent points to the script and uses:

```xml
<key>StartCalendarInterval</key>
<dict>
  <key>Hour</key><integer>8</integer>
  <key>Minute</key><integer>0</integer>
</dict>
```

Useful commands:

```bash
launchctl load ~/Library/LaunchAgents/com.dailymoodscreen.morning.plist
launchctl start com.dailymoodscreen.morning
launchctl unload ~/Library/LaunchAgents/com.dailymoodscreen.morning.plist
```

## Apple Shortcut for recent photos

The companion shortcut exports up to five of the newest photos from the previous day into `recent_photos/`. The vision step uses those local files to infer a theme before the wallpaper pipeline runs.

See [`photos_shortcuts_setup.md`](photos_shortcuts_setup.md) for the full action-by-action setup.

## Configuration

### Base context

```json
{
  "language": "zh-CN",
  "weather": { "condition": "cloudy", "temperature": 12 },
  "photos": { "has_recent_photos": false, "photo_count": 0 },
  "style": {
    "tone": ["literary", "atmospheric", "calm", "emotional"],
    "avoid": ["motivational quotes", "generic inspiration", "cheesy expressions"]
  }
}
```

### Style engine

```json
{
  "language": "zh",
  "writing_style": "gentle",
  "visual_style": "daily_mood",
  "use_ai_background": true
}
```

Set `use_ai_background` to `false` to use the local gradient fallback and avoid image-generation cost.

## Privacy, cost, and limitations

- In the menu bar app, API keys are stored in macOS Keychain. The command-line version reads them from environment variables.
- Recent photos stay in the local project folder, but enabled vision and image-generation steps send relevant content to the configured provider. Review that provider's data policy before using sensitive images.
- AI image and text requests may be chargeable. The gradient fallback avoids image-generation calls but not necessarily text-generation calls.
- This is a personal macOS workflow, not a hosted multi-user service. It does not include accounts, cloud storage, quotas, or team administration.
- Generated writing and imagery are probabilistic; review outputs before sharing them publicly.
